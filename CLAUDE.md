# CLAUDE.md — Kurz

Kurz is a programming language in its design phase. This repository holds the design record;
nothing here compiles yet.

- **[kurz-design.md](kurz-design.md) is the one record of the design.** A decision goes in once
  Simon has chosen it. Something that was proposed and not objected to is marked *assumed*. A
  question nobody has answered goes under "Open" in the turn it comes up, not only into chat.
  `judgment step`
- **Design phase means brainstorming, not building.** Ask the big design choices first, and write
  no compiler, runtime or library code until Simon says build. On 2026-10-01 a working v0 compiler
  was built after asking only for a name and a toolchain; Simon stopped it, and every pick made in
  it was void. `judgment step`
- **A design round is numbered questions**, each with its options, what every option costs and a
  stated lean; Simon answers by number. A wish that cannot hold (a cost assumed away, a guarantee
  no system can give) is contradicted in the reply, not recorded as decided. `judgment step`
