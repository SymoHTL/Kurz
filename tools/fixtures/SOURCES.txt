Where the payloads under tools/fixtures/ and tools/review/fixtures/ come from. Each file is what
the platform really sent: the GitHub answers re-indented and otherwise unchanged, the CLI answers
as printed. A test may edit a loaded payload, and says so where it does. To replace one, capture
it again; do not write it.
